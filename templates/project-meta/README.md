# <project>-meta

Private planning repo for `<project>`. Plans, cycles, and decisions live here. The main output (code, dashboard files, docs) lives in `<project>`, created when there is output to keep.

## Layout
- `AGENTS.md`: what this project is, which repos, how agents work here. Agents read it first.
- Area folders (e.g. `strategy/`, `brand/`), only when that area has docs.
- `cycles/YYYY-MM-DD-<slug>/`: one folder per work item, holding `summary.md`, `plan.md`, `decisions.md`.

## Resume
Read the newest cycle's `summary.md`, `plan.md`, `decisions.md`, then do the next action.

## Rules
PRs only, no force-push. No files over 1 MB, no secrets, no personal data.
